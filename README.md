## 📖 About

SumoChat AI is a modern full-stack AI chatbot inspired by Google Gemini.

It provides secure authentication, intelligent conversations powered by Google's Gemini API, chat history management, user profiles, avatar uploads, and a clean, responsive interface built with React and Tailwind CSS.

---

## ✨ Current Features

- 🤖 Google Gemini AI Integration
- 🔐 JWT Authentication
- 👤 User Login & Registration
- 📸 Avatar Upload
- 💬 Chat History
- 📝 Rename Conversations
- 🗑️ Delete Chats
- 🔍 Search Chats
- 🌙 Modern Dark UI
- 📱 Responsive Design
- 🔒 Password Hashing (bcrypt)
- ☁️ MongoDB Atlas
- 🔔 Toast Notifications
